# snpflowR 0.0.0.9000

Initial research development version. No stable release or CRAN submission.

* Add validated allele-count and genotype constructors and audited locus QC.
* Add restricted diploid biallelic SNP VCF input, with sample-name alignment.
* Implement the published migrant-pool construction with plug-in multilocus GST.
* Expose no-shared-allele exclusions and singular descriptive migration transforms.
* Add paired locus/block contrast bootstrap, unresolved labels, and interval plots.
* Add a seeded forward neutral simulator, automated tests, and research protocols.
* Audit pinned diveRsity/corridoR point-estimator sources on 110 arithmetic
  fixtures; preserve normalization differences and numerical boundary failures.
* Add offline comparator reference tests and boundary regression tests, plus a
  separate workflow for the checksum-verified external source comparison.
* Complete a prospective 15,125-dataset sampling-uncertainty study. Preserve
  interval-calibration failures, full outcomes, and independent arithmetic checks.
* Mark calibration as not established in fit provenance and printed output.
  Numerical estimates and reporting thresholds are unchanged; individual and
  crossed bootstrap candidates remain research-only implementations.
