# Contributing to snpflowR

This is an early research project. Please include the package and R versions,
a minimal reproducible example, expected behavior, and observed behavior when
reporting an issue. Use synthetic or openly licensed data rather than identifiable
or access-restricted samples.

For method changes, state the estimand, assumptions, references, migration
orientation, edge-case behavior, and implications for existing results. Add
meaningful independent checks and retain failure cases. An interval or a high
score must not be described as proof of contemporary migration.

For code changes, update roxygen documentation, examples, tests, and NEWS;
run the documented checks; and describe any changed output or dependency.
Do not import third-party code without preserving its license and attribution.
Do not remove numerical failures by silently replacing zeros with epsilon.

Before release, review the gates in RESEARCH_PLAN.md. Publication claims,
submission, and releases remain decisions of the project maintainer.
